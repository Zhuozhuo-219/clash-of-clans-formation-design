# 部落冲突（国服）18本阵型设计实验室

[![Prototype](https://img.shields.io/badge/status-research%20prototype-orange)](#项目状态)

这是一个面向《部落冲突》中国大陆（腾讯）服务器的 **18本阵型设计研究项目**。当前集中于 44×44 家乡网格、可交互建筑编辑和静态下兵线拓扑，不进行自动阵型生成或精确战斗模拟。

> **重要**：这是社区研究原型，不是 Supercell / 腾讯官方工具。数据以 **2026-11-10** 的18本快照为基线，部分攻击属性引用国际服及第三方资料，**尚未完成国服客户端实测核验**。现阶段的地图边界、禁区与下兵规则也属于待验证的工程模型。

## 快速开始

直接下载仓库根目录的 [`index.html`](index.html)，用支持 Canvas 的现代浏览器打开，即可离线使用；不需要安装依赖，也不需要运行服务器。

当前可进行：

- 44×44 网格的菱形视图 / 俯视视图切换；滚轮缩放、拖动平移。
- 按数量上限放置/移动建筑，检查矩形占位冲突，拖动绘制325段内上限的城墙。
- 绘制普通建筑及城墙外扩一格的禁下兵单元格并集和白色轮廓。
- 将隐藏特斯拉与陷阱设为不单独产生禁下兵区域；标记可能存在的内部可下兵空洞。
- 静态试下兵、撤销/重做、导入导出阵型 JSON、导出画布 PNG。
- 浏览器本地自动保存（以 JSON 导出作为可靠备份）。

**注意**：静态试下兵只判定已实现的禁区模型，尚未包含游戏客户端的地图可建造掩码、四角限制、地图外下兵与实际单位半径判定。游戏内机制请以国服实测为准。

## 下兵线工程约定（v0.1）

采用0–43 的整数坐标、左上角锚点。普通建筑和城墙的每个占格在棋盘8邻域向外扩张一格，所有扩张格合并生成禁下兵集合；集合中每个单元格与集合外邻格相接的边构成白色边界。隐藏特斯拉与陷阱仍然占据摆放格，不可以和其他建筑重叠，但**不单独扩大**禁下兵集合。

这是一项**初步静态假设**，非经国服客户端逐格认证的最终判定。也不把 `null` 的未知属性替换成零。参见 [`docs/topology_spec.md`](docs/topology_spec.md)。

## 运行测试

```bash
node tests/test_topology.js
```

可选浏览器回归测试（需 Python、Playwright 和本机 Chromium）：

```bash

# 按需安装或配置 Chromium；测试脚本默认寻找 /usr/bin/chromium
python tests/test_canvas_layout.py
```
