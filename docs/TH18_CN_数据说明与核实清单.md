# 部落冲突：18本国服阵型设计资料基线（2026-11-10）

## 文件

- `coc_th18_cn_2026-11-10.json`：205条结构化实体条目，包含建筑、陷阱、守卫、兵种、战宠、英雄、超级兵种、法术、攻城机器、装备、助手、轮换精制防御及暂定国服/活动内容。
- `th18_data_quality_report.json`：版本问题、交叉来源冲突与数据完整性报告。

## 核心约定

1. **阵型网格：44×44格、1936格**，工程坐标取左上角 `(0,0)`，右下角 `(43,43)`。这是程序的统一约定；游戏画面的等距投影方向可通过渲染层变换，不改变网格定义。
2. 建筑 `count_max_placed` 是**全部合并完成后**可实际部署的数量，不是历次购入建筑数量。常规加农炮0、箭塔2、法师塔2、多人箭塔3、跳弹加农炮3、超级法师塔2；墙325段。
3. **超级充能分层**：`supercharge.levels` 中第0级是正常满级，第1/2或第3级是充能后的绝对属性值，并非差值。充能类型18种，合并后按实际可部署数量重算为135次充能；某汇总站点显示137次，因错误把多人箭塔计为4座。
4. **守卫三选一；精制防御三选一**。精制台只占一个3×3位置；三种精制防御不分别占三座。
5. `null` 表示未知或不适用。尤其不能把未知的攻击间隔、碰撞/索敌规则、国服数据当作0值处理。
6. `max_level_stats.damage_per_second` 为持续DPS；`damage_per_hit` 为单次命中/陷阱一次触发伤害。多模式、连锁、递增、百分比生命伤害的防御需要额外公式。
7. **来源以国际服及第三方游戏客户端数据为主**，尚未完成腾讯国服战斗属性逐项比对。部分国服与国际服升级时间确实不同，但不代表战斗数值全部不同。
8. 国服客户端的2026年11月数值需补充实测。取不到的数据保留 `null` 及 `verification` 来源/备注，不应输入精准战斗模拟器。

## 暂未完全核验的重要问题

- 44×44矩形内部是否存在保留格、障碍物或特殊可/禁放区域。`buildable_mask` 目前是 `null`。
- 英雄、战宠、兵种和装备的复杂效果（冷却、成长公式、目标优先级、移动/锁定/转向、溅射、投射物飞行时间、建筑修复）尚不适合直接进行高精度模拟。
- 每一种同名单位在国服客户端与国际服的数据一致性；一些游戏速度字段是内部刻度，不能未经换算视作每秒移动格数。
- 空中炸弹18本数量：更新较新的资料为8、个别汇总表为7，采用8并保留冲突。
- 反击之塔攻击周期：以2026年2月官方平衡更新的0.35秒为准，强化门槛5/25/50。不能使用旧版1.2秒和5/20/40。
- 2026年11月全球服宣布19本将于月中到来；本快照以11月10日18本为准，后续应另行保存19本数据版本。

## 推荐研发顺序

第一阶段：用 `buildings`、`traps`、`map.grid` 实现建筑占位合法性、不可重叠、建筑数量与合并约束检查；实现一个守卫槽、一个精制防御槽、阵型地图旋转和导出。

第二阶段：逐项接入中国大陆客户端的地面/空中防御射程，所有陷阱触发范围，定向防御角度及攻击模式；输出覆盖热力图。

第三阶段：在有可靠国服攻击行为数值和录像回放验证后，实现攻防仿真，包括首击延迟、寻路与攻击距离、弹射/溅射、复合机械塔模式、反击阶段与守卫巡逻。

完整公开来源链接及每项的数据核实状态均内置于 JSON 的 `validation.source_catalog` 和各单位 `verification` 字段。
